# Fish Life Span Prediction

Regression ML project to predict fish species life span from biological and ecological features — size, habitat, diet, and species characteristics.

## Files
| File | Description |
|---|---|
| `Fish_Life_Span_Prediction.ipynb` | Main notebook — EDA, modeling, evaluation |
| `experiments.ipynb` | Exploratory experiments and feature tests |
| `data/fish_data.csv` | Fish species dataset |

## Tech Stack
Python · pandas · scikit-learn · matplotlib · seaborn
